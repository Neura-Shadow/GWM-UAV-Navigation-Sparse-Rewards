Release title:

## Summary

This checkpoint completes Phase 5 runtime readiness and guarded SITL validation
infrastructure. It remains mock-first and safe by default: normal tests and
no-gate smoke commands do not launch Isaac Sim, start ROS2 nodes, connect to
MAVSDK / PX4 SITL, launch PX4, run hardware checks, or enable autonomous real
flight.

## Phase 5 Highlights

- Phase 5-A: Runtime Capability Detection
  - Added read-only capability reporting for Python, CUDA visibility, optional
    Isaac Sim / ROS2 / MAVSDK / PX4 availability, GitHub CLI status, and
    allowlisted environment hints.
- Phase 5-B: Guarded Isaac Runtime Smoke
  - Added an optional Isaac Sim runtime smoke runner around `IsaacSimRuntime`,
    gated by explicit environment variables and skipped by default.
- Phase 5-C: Guarded ROS2 Sensor Sync Smoke
  - Added an optional smoke runner for `ROS2SensorSynchronizer`, with synthetic
    mock-message tests and real ROS2 startup gated by operator opt-in.
- Phase 5-D: Guarded MAVSDK / PX4 SITL Smoke
  - Added an optional command-path smoke runner for `MAVLinkBridge` in SITL
    mode, using fake-client tests by default and never launching PX4.
- Phase 5-E: Closed-loop Mock-to-SITL Readiness
  - Added a mock-first readiness runner that executes the Phase 4-F demo path,
    records runtime gate status, checks prior smoke report presence when
    requested, and documents the future closed-loop connection points.

## Safety Defaults

Deployment remains locked down by default:

```yaml
deployment:
  mock: true
  sitl_enabled: false
  real_hardware_enabled: false
  autonomous_real_flight_enabled: false
```

Optional runtime paths remain guarded opt-ins:

- Isaac runtime smoke requires `GWM_RUN_ISAAC_RUNTIME_TESTS=1` and
  `GWM_ALLOW_OPTIONAL_RUNTIME=1`.
- ROS2 sensor sync smoke requires `GWM_RUN_ROS2_SENSOR_SYNC_TESTS=1` and
  `GWM_ALLOW_OPTIONAL_RUNTIME=1`.
- MAVSDK / PX4 SITL smoke requires `GWM_RUN_MAVSDK_SITL_TESTS=1`,
  `GWM_ALLOW_OPTIONAL_RUNTIME=1`, and `GWM_ALLOW_SITL_COMMANDS=1`.

## Known Limitations

- No real hardware flight validation.
- No autonomous real flight.
- No formal CBF certification proof.
- No automatic PX4 launch.
- Optional Isaac / ROS2 / MAVSDK paths are guarded runtime hooks and smoke
  tests, not required normal-test dependencies.
- Closed-loop readiness is a mock-first orchestration check, not proof of
  real-world navigation performance or production readiness.
- Runtime smoke reports under `outputs/` are machine-specific artifacts and
  should not be committed.
