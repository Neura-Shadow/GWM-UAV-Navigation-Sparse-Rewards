## Phase 7-B Summary

Cosys-AirSim / legacy AirSim sessions. It remains simulation-only and does not
replace the Phase 6 Isaac + ROS2 + PX4 SITL + MAVSDK baseline.

Highlights:

- Optional live validation runner for externally started Cosys-AirSim / legacy AirSim sessions
- Cosys-AirSim / `cosysairsim` preferred
- Legacy AirSim / `airsim` fallback
- Backend registry key remains `airsim`
- No-gate run skips safely
- Live session validation remains explicitly gated
- Zero-command validation requires `GWM_ALLOW_AIRSIM_API_CONTROL=1`

## Safety Boundaries

- Cosys-AirSim, legacy AirSim, and Unreal are never launched by the repository.
- Live validation requires an externally started simulator session.
- No physical UAV hardware, PX4 hardware, ROS2, Isaac Sim, MAVSDK/PX4 SITL,
  Nav2, or hardware checks are part of this release.
- Zero-command validation sends only zero velocity when explicitly gated.
- The release does not enable autonomous real flight.
- The release does not claim real flight validation, production readiness, or
  certified safety.

## Known Limitations

- Normal tests do not perform live Cosys-AirSim or legacy AirSim validation.
- Runtime reports are machine-specific artifacts under `outputs/` and should
  remain uncommitted.
- Coordinate metadata is preserved as `airsim_ned`; no silent conversion to
  Isaac Z-up or project frames is performed.
