## Safety Boundaries

- Real hardware remains disabled by default.
- Autonomous real flight remains disabled by default.
- Cosys-AirSim and legacy AirSim live paths are optional guarded opt-ins.
- The repository does not launch Unreal or AirSim automatically.
- The Phase 6 Isaac + ROS2 + PX4 SITL + MAVSDK path remains the guarded
  full-stack pure-simulation baseline.
- The release does not claim production readiness, real flight validation, or
  certified safety.

## Known Limitations

- No live Cosys-AirSim or legacy AirSim validation is included in normal tests.
- Optional AirSim-family runtime smoke requires an externally running simulator
  and explicit environment gates.
- Coordinate metadata is preserved, but AirSim NED is not silently converted to
  Isaac Z-up or project frames.
- Backend comparison reports schema/readiness compatibility only; it does not
  claim simulator performance parity.
