# v0.3.0-mock-first Release Note

Tag: `v0.3.0-mock-first`

Commit: `b9db3b0`

## Summary

`v0.3.0-mock-first` is the first full mock-first research framework checkpoint.
It completes the repository baseline across world-model training,
Real2Sim2Real data flow, ROS2-style middleware abstraction, Isaac Sim /
OpenUSD-style scene descriptors, distributed multi-agent coordination, and
deployment-facing safety interfaces.

This release is intentionally mock-first. It does not require GPU, AirSim, ROS2,
Isaac Sim, PX4, ArduPilot, MAVSDK, Nav2, SITL/HIL infrastructure, or real UAV
hardware.

## Highlights

- Phase 1: research-ready refactor with modular packages, mock environments,
  interfaces, documentation, and tests.
- Phase 2: simulation-driven training and evaluation path, including world
  model training, sparse curriculum support, and Real2Sim2Real loop scaffolding.
- Phase 3-A: guarded ROS2 bridge and adapter contracts that import and test
  without ROS2 installed.
- Phase 3-B: Isaac Sim / OpenUSD-style scene descriptor generation with JSON
  export and mock USD stage support.
- Phase 3-C: distributed coordination infrastructure with mock DDS fallback,
  priority-based assignment, shared latent maps, and swarm strategy extension.
- Phase 3-D: mock deployment interfaces for MAVLink, hardware state,
  Nav2-style costmap/planner skeletons, and baseline CBF-style filtering.

## Final Stabilization

The final stabilization pass clarified README and architecture documentation,
kept the roadmap aligned with mock-first status, and corrected ignore rules so
the real source package under `src/env/` remains tracked while generated
environment folders stay ignored.

The release keeps `.codegraph/` local-only and untracked.

## Safe Defaults

Deployment configuration remains safe by default:

```yaml
deployment:
  mock: true
  real_hardware_enabled: false
  autonomous_real_flight_enabled: false
```

Emergency-stop, safe-hover, safe-land, command saturation, and CBF-style action
filtering are represented as mock-first interfaces and tests. They do not
authorize real autonomous flight.

## Known Limitations and Non-goals

This release does not include real PX4, ArduPilot, MAVSDK, ROS2 runtime,
Nav2 runtime, Isaac Sim runtime, SITL/HIL automation, real hardware tests, real
flight validation, or formal safety certification. Real deployment interfaces
remain future work beyond this mock-first checkpoint.
