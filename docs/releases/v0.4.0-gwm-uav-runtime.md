## Summary

This checkpoint completes the Phase 4 Generated World Model UAV runtime demo
baseline. It remains a mock-first research framework: normal tests and demo
smoke checks run without Isaac Sim, ROS2, MAVSDK, PX4, GPU, SITL, or real UAV
hardware.

## Phase 4 Highlights

- Phase 4-A: Generated World Model Core
  - Added lightweight PyTorch observation encoding, action conditioning,
    video-dynamics prediction, autoregressive rollout, trajectory scoring,
    synthetic dataset utilities, and CPU-safe training.
- Phase 4-B: Future Frame Projection
  - Added a pure PyTorch / NumPy geometry prior for projecting RGB/depth frames
    across poses with explicit coordinate-conversion metadata.
- Phase 4-C: Guarded Isaac Sim Runtime Adapter
  - Added optional Isaac Sim runtime and `BaseNavigationEnv` compatibility with
    fake-backend tests and no Isaac Sim requirement for normal regression.
- Phase 4-D: ROS2 Sensor Sync
  - Added mock-first synchronization for RGB, depth, LiDAR, optional IMU, and
    odometry into `SensorObservation` / `ObservationBuffer`.
- Phase 4-E: MAVSDK / PX4 SITL Command Path
  - Added guarded MAVSDK / PX4 SITL command plumbing with fake-client tests,
    explicit SITL opt-in, and no automatic PX4 launch.
- Phase 4-F: End-to-End GWM Navigation Demo
  - Added the mock-first demo pipeline connecting observation source,
    `ObservationBuffer`, generated rollout planning, trajectory scoring, CBF
    safety filtering, and mock command execution.

## Safety Defaults

Deployment remains locked down by default:

```yaml
deployment:
  mock: true
  sitl_enabled: false
  real_hardware_enabled: false
  autonomous_real_flight_enabled: false
```

Optional Isaac Sim, ROS2 sensor synchronization, and MAVSDK / PX4 SITL paths
remain guarded opt-ins. Real hardware and autonomous real flight flags are
rejected by the demo path.

## Known Limitations

- No real hardware flight validation.
- No autonomous real flight.
- No formal CBF certification proof.
- Optional Isaac / ROS2 / MAVSDK paths are guarded integration hooks, not
  required runtimes.
- No automatic PX4 launch.
- No production-readiness claim.
